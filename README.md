# Novalnet Flutter SDK

The Novalnet Flutter SDK empowers developers to seamlessly integrate a secure, scalable, and feature-rich payment experience into their Flutter applications. Designed for efficiency and flexibility, the SDK provides a comprehensive set of ready-to-use and customizable UI components that simplify the process of collecting and managing user payment details.

With built-in support for multiple payment methods and a focus on security and compliance, the Novalnet Flutter SDK enables you to deliver a smooth and reliable checkout experience while significantly reducing development effort. Whether you're building a new app or enhancing an existing one, the SDK ensures a consistent, user-friendly payment flow across platforms.

## Getting Started

This project is a starting point for a Flutter
[plug-in package](https://flutter.dev/to/develop-plugins),
a specialized package that includes platform-specific implementation code for
Android and/or iOS.

For help getting started with Flutter development, view the
[online documentation](https://docs.flutter.dev), which offers tutorials,
samples, guidance on mobile development, and a full API reference.

The plugin project was generated without specifying the `--platforms` flag, no platforms are currently supported.
To add platforms, run `flutter create -t plugin --platforms <platforms> .` in this directory.
You can also find a detailed instruction on how to add platforms in the `pubspec.yaml` at https://flutter.dev/to/pubspec-plugin-platforms.
